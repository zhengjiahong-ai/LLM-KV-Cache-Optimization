# Research Consolidation

This directory contains the project's cross-phase research synthesis and evidence navigation.

## Core documents

1. [Research Results and Contributions](research-results-and-contributions.md)  
   The M1 R1.2 synthesis answering:
   - What do the experiments across phases actually establish?
   - Which hypotheses were supported, not supported, failed their gates, or were not identifiable?
   - What system, measurement, mechanism, and experimental-method contributions are defensible?

2. [R1 Cross-Phase Experiment and Evidence Ledger](r1-experiment-evidence-ledger.md)  
   Campaign lineage, source precedence, evidence tiers, experimental units, result provenance, and links to primary reports.

## Reading order

1. Start with [canonical research status](../research-status.md) for the current project state and pending decisions.
2. Read [Research Results and Contributions](research-results-and-contributions.md) for the integrated scientific interpretation.
3. Use the [R1 evidence ledger](r1-experiment-evidence-ledger.md) to trace each statement to its original campaign, protocol, archive, and report.
4. For a formal claim, cite the frozen protocol and primary result report rather than this synthesis alone.

## Status and boundaries

- The synthesis is an M1 working draft; it does not replace final M1/M4 adjudication.
- Historical experiment reports, frozen protocols, and immutable archives are not modified by these documents.
- Different campaigns, statistical units, estimands, and policy definitions must not be pooled merely because they share a phase label or arm name.
- No GPU run, Native smoke, algorithm implementation, or Protocol v5 is authorized by this documentation set.
