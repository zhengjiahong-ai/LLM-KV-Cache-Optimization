## 0. 结论

**A1 的成本模型确实与冻结淘汰规则结构性错配，但该错配在可验证语料上没有转化为损失差异。
因此不建议沿"改进 Entry 代价函数"的方向继续投入。**

具体地：

| 命题 | 结果 |
|---|---|
| A1 的成本表达与实际淘汰不一致 | **成立**，且可量化（§2） |
| 该不一致导致 A1 作出更差的选择 | **不成立**（§3，真实语料 78/78 最优） |
| 换用更好的代价模型（本文原拟的 ERC）能带来收益 | **否证**（§4.1） |
| 改成集合决策（本文原拟的 MUS）能带来收益 | **否证**（§4.2） |

这是 M1 明确要求的情形：「如果分析发现当前已有方法已经足够好，也应明确报告，不必强行提出新算法。」
本文即按此报告，并说明**为什么**更精细的代价函数在这里必然落空。

## 1. 先看冻结规则与 A1 各自优化什么

`src/kvopt/continuum/selection.py`：

```text
virtual_eligible_order = sorted(eligible, key=(eligibility_tier, native_lru_rank))
selected               = virtual_eligible_order[:target]
TIER_1 = hashless（恒可回收，无内容）    TIER_2 = hashed 且全部 owner 已释放
```

`src/kvopt/costaware/a1_entry.py`：

```text
N_i    = |newly_eligible_after(i)|
Rhat_i = q_i * [ min(need, N_i) + λ * (N_i - min(need, N_i))^+ ]
```

**$N_i$ 数的是「有多少块从受保护变成可回收」，不含 rank、不含 tier 区分、
也不含「实际会淘汰谁」。** 这是一个真实的建模缺口，不是风格问题——§2 给出两个反例。

## 2. 缺口是真实的（两个反例 + 真实语料量化）

### 2.1 反例一：为不会被淘汰的块付费（合成）

`relief_not_eviction()`：队列 rank 0..5，前 3 块 hashless，后 3 块由 entry `e` 独占，
`target = 3`。

```text
before: eligible = 3, target = 3          <- 目标已满足，不需要任何释放
N_e                                      = 3
实际被淘汰（释放 e 之后）                 = [0, 1, 2]   <- 仍是那 3 个 hashless 块
释放 e 导致的真实重算                    = 0.0000
A1 为 e 计费 q_e * N_e                   = 2.7000
```

A1 支付了 2.7，而该决策真实死亡的内容为零。此项与 $q$ 完全无关。

### 2.2 反例二：相同 relief，不同真实损失（合成）

`warm_vs_cold()`：`target = 1`，两个 entry 各解锁一个块，**$N_i$ 都是 1**。

| 释放 | 解锁块 | 深度 / 前缀长 | 真实损失 |
|---|---|---:|---:|
| `cold` | 10 | 1 / 3 | **1.5000** |
| `warm` | 11 | 3 / 3 | **0.5000** |

```text
A1 score cold = 0.5000, warm = 0.5000  -> identical
```

### 2.3 真实语料：缺口确实存在（H1，90 个 forced-release 决策）

| 统计 | 值 |
|---|---|
| 有释放的决策 | 90 |
| 平均「解锁但从未被淘汰」的块数 | **8.767** |
| 出现该情形的决策数 | **53 / 90** |
| 最大值 | 30 块 |

> **结论：A1 在 59% 的决策中为最终存活的内容计费。** 这条确认为真。

## 3. 但缺口**不转化为**损失差异（这是本报告的核心）

### 3.1 同 relief、不同淘汰集 —— 100% 不同，0% 有损失差异

从**空释放状态**出发（A1 做第一次选择时面对的状态），比较所有 $N_i$ 相等的 entry 对：

```text
singleton pairs with equal N_i:  99
... that evict different blocks: 99     (100%)
... that incur different LOSS:   0      (0%)     <- the one that matters
```

补充核查（排除"差异块只是无内容块"这一平凡解释）：

```text
differing blocks are ALL hashless: 0
differing blocks include hashed  : 99      <- 差异确实是带内容的块
equal-N pairs with IDENTICAL shallowest-cut profile:  0
equal-N pairs with DIFFERENT shallowest-cut profile: 99
```

**即：切哪个前缀、切在哪一层，全都不同；但总损失恰好相同。**

### 3.2 A1 在真实语料上已经是最优的

与**可行**替代方案逐决策比较（同样从空状态，均匀 $q$ 以隔离结构因素）：

| 对照 | 结果 |
|---|---|
| 存在可行单 entry 的决策 | 63 |
| 该单 entry 优于 A1 的 | **0** |
| 存在穷举最优解的决策（$\lvert S\rvert\le3$） | 78 |
| 某个集合优于 A1 的 | **0** |
| A1 平均超出最优 | **0.0000** |
| A1 最大超出最优 | **0.0000** |

**A1 的代价模型是错的，但它的选择是对的。** 这两件事同时成立，正是本文的关键发现。

### 3.2.1 为什么合成探针显示 477/3000 次优，真实语料却是 0/78

初稿依赖合成探针（`a1_structural_gap.py`，477/3000 次优，最大差距 3.09），
该结果**不能**外推到真实语料，原因有二，必须写明：

1. **合成生成器给各 entry 赋了差异很大的 $q$**（0.2–0.9 随机），
   而真实语料用 deadline 导出的 $q$ 时，$\Delta q$ 只有约 0.001 量级（§3.3）；
2. **合成生成器随机打乱 rank**（25% 共享率 + 无序 rank），因此大量制造了
   「最浅切面可被改变」的几何；真实 H1 语料中 rank 与 owner 分布并非如此。

换言之：合成探针证明了**缺口在原理上可导致损失差异**，
真实语料说明**该原理性差异在实际分布下不出现**。
本文以真实语料为准；合成结果仅作为存在性证明保留。

### 3.3 用真实 deadline 代理 $q$ 后，余量仅 0.0013 块

唯一剩下的杠杆是 $q$（跨 entry 权重）。用真实
`retention_deadline_timestamp` 计算 $q=\sigma((d-t)/\tau)$，$\tau=30$：

| 指标 | 均匀 $q$ | 真实 deadline $q$ |
|---|---:|---:|
| 某集合优于 A1 的决策 | 0 / 78 | 36 / 78 |
| A1 平均超出最优（块） | 0.0000 | **0.0013** |
| A1 最大超出最优（块） | 0.0000 | **0.0156** |

排除饱和解释（`target ≥` 全释放后的 eligible 数，22/90 为饱和）：

| 子集 | 决策数 | 平均余量 | 最大余量 |
|---|---:|---:|---:|
| 饱和 | 22 | 0.0013（deadline） | — |
| **非饱和** | 56 | **0.00186** | 0.0156 |

> 余量约为 **0.002 块 / 决策**。乘上块大小（16 token）约为 **0.03 token / 决策**。
> 这个量级低于任何可观测的 token 噪声，也低于 PR #68 中 A2 的 proxy 差异量级。

## 4. 我原先提出的两个候选，均未通过自己的否证测试

写作本报告的初稿时我提出两个候选（ERC / MUS）。按 M1 要求先做离线否证检验，
**两者都被自己的判据否证**，记录如下——这本身是结论的一部分。

### 4.1 候选 A：Eviction-Realised Cost（ERC）—— 否证

**原假设**：把代价建立在「实际会被淘汰的块」而非「解锁的块」上，即可获得收益。
**判据（原定）**：若「解锁集 ≠ 淘汰集」与「同 relief 不同淘汰集」的占比可忽略，则无空间。

实测：前者占比 59%（有空间），**但后者中损失差异为 0%（无收益）**。
即 ERC 修正了一个**不影响目标的**误差。

**否证成立**：ERC 的决策与 A1 在 78/78 决策上等价（均匀 $q$），
在真实 $q$ 下余量 0.0013 块。ERC 不值得实现。

> 原因（结构性）：损失只依赖**每条链最浅被淘汰深度** $j_c$。
> 修改选择只能改变「哪些深层块死」，而损失的读数是 $\min$ 深度。
> 只要最浅切面不变或总后缀长度不变，代价就不变。
> 这与 A2 阶段引理 B 的形态**完全相同**——同一堵墙，只是换了一层。

### 4.2 候选 B：Minimal Unlock Set（MUS）—— 否证

**原假设**：顺序贪心会过度释放；改为极小集合搜索可获得收益。
**判据（原定）**：若 A1 的基数总等于最优基数，或基数差异不产生损失差异，则无空间。

实测：A1 平均集合大小 2.033，最小可行 1.833，**过度释放 12/90（13.3%）**。
基数差异存在，**但这些决策的损失差异为 0**（§3.2 的 0/78）。
即 A1 释放了多余 entry，却没有为此付出任何代价——因为多释放的那点解锁量
没有改变最浅切面。

**否证成立**：MUS 减少的是 entry 释放次数（一个资源成本），不是重算损失（目标）。
除非 Entry 释放本身有代价（例如破坏未来复用），而该代价在本轮不在目标函数内。

### 4.3 $\lambda$ 也不能修复

合成探针（3000 决策）：

```text
lambda=0.0  mean realised loss 1.6174   A1-worse 311
lambda=0.5  mean realised loss 1.6408   A1-worse 304   <- 当前配置
lambda=1.0  mean realised loss 1.7042   A1-worse 336
```

差异小且非单调。**$\lambda$ 调的是「要不要偏好小 $N_i$」，而问题是 $N_i$ 本身不是代价。**

## 5. 回答 M1 的五个问题

### 5.1 Existing A1 Limitation

**可证明**：A1 的代价量（解锁块数）与冻结规则的实际淘汰集不一致，59% 的决策中为存活内容计费（§2）。
**不可证明**：该不一致导致更差的选择。真实语料上 A1 与穷举最优完全一致（78/78）。

### 5.2 Unexploited Information

决策时合法可得但未被使用的信息确实存在（`native_lru_rank`、tier 组成、
解锁块的前缀深度）。**但它们不携带可转化为目标的增量价值**——
因为它们只影响「哪些深层块死」，而损失读 $\min$ 深度。

> 这一条不是"未测"，而是"测了，值为零"。

### 5.3 Optimization Structure

- 损失对释放集**非单调**（真实语料 656/3000 合成决策；真实语料见 §4.2 的 12 例过度释放）；
- 存在非加性（联合解锁）；
- **但这些结构都不改变最浅切面**，因此不产生目标差异。

**判断：Entry Release Set 的组合结构真实存在，但对当前目标的贡献为零。**

### 5.4 Candidate Method

原拟两个，**均被自己的判据否证**（§4）。按 M1 指示，不强行改推新算法。

若要继续，真正未探索的方向**不是**改进代价函数，而是：

> 改变**可行域**本身——即让 Entry 释放决策能够影响「哪些块可回收」的构成，
> 而不仅是「何时可回收」。

这是 A3 的另一条路径，需要单独授权，且必须先证明该可行域变更会产生最浅切面的差异。
本轮不提出具体方案。

### 5.5 Falsifiability

本文的否证判据已执行，结果如下：

| 判据 | 阈值 | 实测 | 判定 |
|---|---|---|---|
| 解锁集 ≠ 淘汰集 的占比 | 需显著 | 59% | 有缺口 |
| 同 relief 不同淘汰集的**损失**差异率 | 需显著 | **0%** | **否证** |
| A1 相对穷举最优的余量（均匀 $q$） | 需 $>0$ | **0.0000** | **否证** |
| A1 余量（真实 deadline $q$） | 需 $>0.1$ 块 | **0.0013** | **否证** |

## 6. 为什么会这样 —— 与 A2 的同一堵墙

| | A2（Block 层） | 本轮（Entry 层） |
|---|---|---|
| 缺口形式 | $q$ 与真实复用无关 | 代价量 ≠ 实际淘汰集 |
| 实测余量 | proxy 差异 0（无反转时） | 损失差异 0（均匀 $q$） |
| 共同机制 | **APC 损失只读每条链的最浅缺口 $\min$ 深度** | 同左 |
| 结论 | 无可利用空间 | 无可利用空间 |

两层都撞在同一处：**APC 的损失函数对"选哪个深层块"不敏感**。
A2 试图用 $q$ 在链间重新分配，Entry 层试图用 $N_i$ 重新分配，两者都只能在
**最浅切面**上产生差异，而最浅切面由「释放谁 ⇒ 谁的 owner 全部释放 ⇒ 哪些块变可回收」
加上 rank 截断共同决定，A1 的 $N_i$ 与之一致性足够高。

> 这是本轮最有价值的结论：**两层失败不是两次偶然，而是同一个结构事实的两次显现。**
> 后续任何新方法都应先证明它能改变**最浅切面**，否则无论目标函数多精细都不会有收益。

---

## 7. 建议

1. **不建议**沿「改进 Entry 代价函数」继续（ERC/MUS 已否证）。
2. **不建议**继续调整 $\lambda$、$\tau$ 或引入更复杂的 $q$。
3. 若仍要研究 Entry 层，唯一有价值的问题是**可行域**：能否让释放决策改变
   可回收块的**构成**（而非仅时点）。这需要新的授权，且第一件事是证明
   该变更会产生最浅切面的差异。
4. 否则应考虑 **A1 已足够，本轮研究线收束**，把 A1 的负面/边界结果作为论文的
   消融与限制章节，而不是继续寻找新的 Cost-Aware 变体。
