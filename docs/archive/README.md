# Documentation Archive

This directory preserves historical project material that is no longer part of the active project specification.

Archived files are retained for provenance, review history, and reproducibility. Moving a file here does **not** invalidate the historical evidence it records; it only means that later documents now carry the active project status.

## Layout

- `phase1b-continuum/` — Phase 1B feasibility mapping and observation-spike evidence that were superseded by the completed implementation and final validation report.
- `related-work/` — paper PDFs, detailed per-paper notes, and comparison notes used to build the higher-level background/motivation documents.
- `project-setup/` — early repository-development guidance superseded by `docs/git-workflow.md`.

## Active Phase 1B sources

For the completed Continuum-style baseline, use these active documents first:

1. `docs/baseline-freeze.md` — frozen baseline scope and acceptance criteria.
2. `docs/phase1b-continuum-implementation-decisions.md` — exact implementation semantics.
3. `docs/continuum-baseline-implementation.md` — final implementation record.
4. `docs/experiments/phase1b-continuum/final-report.md` — final runtime validation and experiment evidence.

Historical archived documents should be consulted only when the evolution of a decision or low-level observation provenance is needed.
