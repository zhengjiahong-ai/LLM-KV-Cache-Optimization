# Documentation Archive

This directory preserves superseded design spikes, intermediate implementation records, and historical decision documents.

Archived files remain useful for provenance and reproducibility, but they are **not current project-status entry points**. Current project state should be read from:

- `README.md`;
- `docs/experiment-plan.md`;
- `docs/team-responsibilities.md`;
- `docs/architecture.md`;
- `docs/backend-selection.md`;
- `docs/baseline-freeze.md`;
- the relevant final experiment report.

## Phase 1B Continuum archive

`phase1b-continuum/` contains the feasibility mapping, observation-spike evidence, implementation-decision record, and the superseded in-progress implementation record used while Phase 1B was being built.
