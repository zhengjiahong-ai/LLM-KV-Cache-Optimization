## 引用口径

- **Continuum。** v6 摘要、引言中的整体最大改善与 §6.2 的特定重放对比不使用同一实验口径。8.18× 的具体负载点与对照未逐项标定。GLM-4.5-fp8 出现在 §6.4 rollout microbenchmark，不能并入 §6.1 的重放配置。
- **SAGA。** Table 2 的 2.84 和 1.31 来自 SWE-bench 列，1.86 来自 LRU + Prefix 的 Mean 列。SWE-bench 对应的 LRU + Prefix 数值是 1.97。作者名按 PDF 的 Siu-Ming Yiu 记载，arXiv 页面显示 Siu Ming Yiu。
- **KVFlow。** §3.1 为 Workflow-Aware Eviction Policy，§3.2 为 Overlapped KV Prefetching。PDF 与对应 arXiv 页面均写作 Ajjkumar Patel。
- **CacheWise。** §1 的 request completion time 与 §6.1–6.3 的 session 指标措辞不同。本文按实验节对会话完成时间的定义引用，并分开完整系统与消融。
- **WFEF。** §3.2 的 14 种在线算法包含 LRU 和 LRB，Bélády 离线最优单列。论文承诺发布 trace 与模拟器，实际发布状态未核实。
- **PagedAttention。** 论文中的抢占与恢复说明属于当时的 vLLM。旧版 APC、CPU offload API、历史 kernel 与 RFC #37003 的引用边界见 [vLLM 参考文档](关于vLLM的参考文档与网址.md)。

结果的完整条件与适用边界见[论文总结](../论文总结.md)。
