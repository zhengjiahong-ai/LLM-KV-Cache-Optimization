## 4. 使用规则

1. **引用性能数字必须同时引用实验条件**（集群规模、模型、基线版本、重复次数、显著性、容量点）。条件缺失的数字视为不可用。
2. **不得**把上表任何论文的性能数字描述为本项目的实测或预期结果。
3. **区分四个层次**：论文作者报告的结果 / 论文机制在本项目中的设计启发 / 本项目提出的假设 / 本仓库实测结果。四者不可混写。
4. **区分决策层**：内存布局、驱逐（victim selection）、保留时长（TTL）、保护与释放（unpin）、准入与调度、预取/offload、工作流级协调。跨层比较默认不公平，必须显式说明。
5. 若某篇论文更新版本，先更新本表，再同步 `论文总结.md` 与 `相关工作总结.md`。
