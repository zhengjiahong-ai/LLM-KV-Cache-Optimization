## 4. 使用规则

1. **引用性能数字必须同时引用实验条件**（集群规模、模型、基线版本、重复次数、显著性）。条件缺失的数字视为不可用。
2. **不得**把上表任何论文的性能数字描述为本项目的实测或预期结果。
3. **区分三个层次**：论文作者报告的结果 / 论文提供的设计启发 / 本项目提出的假设。三者不可混写。
4. 若某篇论文更新版本，先更新本表，再同步 `论文总结.md` 与 `相关工作总结.md`。
